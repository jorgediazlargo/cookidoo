# Recetas Thermomix → Cookidoo

Recetas propias en `recetas/*.toml`, publicadas en
https://jorgediazlargo.github.io/cookidoo/ con datos estructurados
schema.org/Recipe. Se suben a Cookidoo con la API de recetas creadas (el importador por URL no admite webs externas).
